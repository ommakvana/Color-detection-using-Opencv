# 🎨 Color Detector & Extractor
This application allows users to detect, highlight, and extract specific colors from images with ease. Users can specify target colors either by inputting RGB/HSV values or by directly clicking on the image. The program identifies all pixels that match the selected color within a user-defined tolerance level and provides two key functionalities:

🔍 Highlight Mode – Visually highlights matching color regions in the original image.

✂️ Extract Mode – Isolates and extracts matching regions to a new image with transparency or a solid background.

✨ Key Features
Select colors via RGB/HSV input or by clicking on the image.

Adjustable color matching tolerance for fine control.

Option to highlight matching pixels or extract them into a separate image.

Simple, interactive GUI for a user-friendly experience.

Ideal for designers, developers, and anyone needing precise color-based image processing.
